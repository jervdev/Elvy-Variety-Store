# Elvy Variety Store

A responsive website for a tools and equipment store, created using HTML, CSS, and JavaScript.

[View the website](https://jervdev.github.io/Elvy-Variety-Store/)

Features include product browsing and search, a shopping cart, repair information, and contact forms.

This is a frontend project. Account and rating features are demos. Checkout and inquiry forms prepare email requests for customers to send manually.
